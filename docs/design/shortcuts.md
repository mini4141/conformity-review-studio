# Keyboard shortcuts

Plain keys are ignored while typing in a field. `Cmd/Ctrl+K` always works.

| Keys | Action | Where |
|---|---|---|
| `j` / `k` | Next / previous finding | Workspace (queue: next / previous row) |
| `a` | Accept the selected finding | Workspace |
| `r` | Reject the selected finding | Workspace |
| `e` | Edit (correct) the finding: verdict, reason, evidence | Workspace |
| `g` then `c` | Go to clause (palette, clauses only) | Any file screen |
| `Cmd/Ctrl+K` | Command palette | Everywhere |
| `?` | Shortcut sheet | Everywhere |
| `/` | Focus the file filter | Queue |
| `Enter` | Open the file | Queue |
| Arrow keys | Move the active cell | Matrix |
| `Enter` | Edit the active cell (verdict, reviewer, comment) | Matrix |
| `Esc` | Cancel an edit / close a dialog | Matrix, dialogs |
| `Tab` | Commit a cell edit | Matrix |
| `Cmd/Ctrl+Enter` | Save a correction | Correction editor |

Every shortcut appears as a key cap on its button or menu item.
